1. Introduction

CharlesTech ("CharlesTech," "we," "us," or "our") respects your privacy. This Privacy Policy explains how CharlesTech ESP32 Technician Suite ("the Application") handles information when you install and use the Application.

The Application is a Windows desktop technician tool for ESP32 and NodeMCU development, programming, firmware flashing, firmware reading, device diagnostics, serial communication, firmware analysis, and related technician functions. The Application is designed to operate primarily on the user's Windows computer and to minimize the collection of personal information.

2. Information We May Process

Depending on the features you use, the Application may process information locally on your computer.

Device and machine information: The Application may use a machine identifier or Windows device identifier for software licensing, activation, trial management, and license validation. This may include Windows MachineGuid or an equivalent machine identifier, machine name, operating-system information, application version, product/license information, and a derived machine identifier used for license activation. The Application does not use this information to track your physical location.

License and activation information: If you activate the Application, license-related information may include customer name and email address if voluntarily provided, license ID, product/license type, machine-specific license identifier, license issue date, PayPal transaction/reference information when supplied for activation, and a cryptographic license signature. License information is used for activation, verification, support, and administration.

ESP32, NodeMCU and connected-device information: When hardware is connected, the Application may process COM/serial port information, baud rate, ESP32/ESP8266/NodeMCU device information, chip identification, flash memory information, firmware images, binary files, serial communication data, diagnostics, firmware analysis information, and read/write operation information.

3. Firmware and User Files

The Application may allow you to open, read, write, analyze, compare, back up, or otherwise process firmware and other files selected by you, including .bin firmware files, ESP32 firmware images, ESP8266/NodeMCU firmware, Arduino-related project files, firmware backups, configuration files, and diagnostic reports.

CharlesTech does not claim ownership of your firmware, source code, projects, or other files. You are responsible for ensuring that you have the appropriate rights to access and modify content processed using the Application.

4. How Information Is Used

Information processed by the Application may be used for software activation, trial management, license verification, device identification, firmware programming, firmware reading and backup, firmware analysis, serial communication, diagnostics, device management, report generation, troubleshooting, Application functionality, and customer support.

CharlesTech does not use information processed by the Application for behavioral advertising.
